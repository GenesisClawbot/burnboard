Rules

  • This is a game, not an audit. Submissions are on the honor system.
  • One row per GitHub account. The latest submission wins.
  • Plausibility checks run on every submission: the payload must parse, counts must be whole and non-negative, the time span must be real, and the burn rate must stay under 5,000,000,000 tokens a day. Rows over the ceiling are listed, not ranked.
  • Ranking is by total Claude Code tokens: input + output + cache create + cache read. The counter reconciles with ccusage token for token; the method is published.
  • Moderation is closing an issue. A closed issue leaves the board on the next build.
